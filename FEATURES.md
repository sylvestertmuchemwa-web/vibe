# Vibe feature plan

## Prototype now
- Home feed
- Create local text posts
- Like/unlike posts
- Explore placeholder
- Notifications placeholder
- Profile placeholder

## Planned features
- User registration and sign-in
- User profiles and profile pictures
- Cloud-saved posts
- Comments and replies
- Following and followers
- Image and video posts
- Communities
- Search and discovery
- Notifications
- Report and block tools
- Privacy and account deletion controls

Features listed as planned are not implemented yet.
