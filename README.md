# Vibe Website Prototype

A responsive social-media-style website prototype made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — responsive design and themes
- `script.js` — demo feed, create-post, likes, search, and navigation
- `assets/icons/vibe-mark.svg` — Vibe logo mark
- `assets/images/` — image assets folder for future additions
- `docs/FEATURES.md` — feature roadmap

## Run locally
Open `index.html` in a modern browser. No build tools are required.

## Publish with GitHub Pages
1. Upload all files and folders to your GitHub repository.
2. Open the repository's **Settings**.
3. Find **Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site.

## Prototype limitations
This is a front-end demo only. Posts and likes are saved in the current browser using local storage. They are not shared with other people and there is no real sign-in, cloud database, messaging, or server-side moderation yet.

Do not enter private information into this demo. Before a public launch, add secure authentication, a backend database, privacy controls, reporting/blocking, moderation, and appropriate safeguards for younger users.
